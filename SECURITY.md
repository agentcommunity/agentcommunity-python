# Security policy

## Supported versions

While the SDK is in the 0.1 alpha series, only the latest 0.1 patch release is
supported with security fixes. Older releases should be upgraded before a
report is evaluated.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Report it
privately to `support@agentcommunity.org` and include the affected version,
impact, reproduction steps, and any suggested remediation. The official
[Agent Community contact page](https://agentcommunity.org/contact) is the source
for current contact routes.

Do not include secrets or personal data beyond what is necessary to explain the
issue. We will acknowledge the report and coordinate disclosure after triage.
